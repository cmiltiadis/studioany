#+title: Readme

Website studioany.com implementing Academic/HugoBlox/Wowchemie templates (starter: [[https://github.com/wowchemy/starter-hugo-academic][wowchemy/starter-hugo-academic]])
+ Uses Wowchemy v5 (2023), *vendored and patched* in =_vendor/= to build with current Hugo (tested with 0.170.1, extended)
  + Wowchemie Hugo Academic was updated to Hugo Blocks, with breaking changes (shortcodes like gallery don't work) -- not adopted
  + The theme is no longer fetched: edit =_vendor/= directly. Do NOT run =hugo mod vendor= / =hugo mod get= (it would overwrite the patches)
    (=go.mod= / =go.sum= were removed for this reason; Hugo reads modules from =_vendor/=)
  + Patches (2026-11, see git log): removed functions (getCSV, resources.ToCSS, site.GoogleAnalytics, IsMultiLingual, IsNode, AllPages, .Site.Data, LanguageCode),
    new template lookup (=_partials/=, no dots in block file names), uint64 =view:= numbers, summaries rendered as before (plain text, ~30 words), Dart Sass
  + Requires Dart Sass (bundled with the snap package; installed in GitHub Actions & by =netlify-build.sh=)
  + Gotchas with new Hugo: YAML front matter must not repeat keys; images must have the right extension (WebP saved as .jpg fails);
    author folder names must match the name in =authors:= incl. accents (e.g. =dubravka-sekulić=)

* Writing conventions
+ Summaries: =What at Venue. City, Year= -- no trailing period, no months (e.g. =Presentation at Drifts Festival. Helsinki, 2021=)
  + Publications: =Paper at eCAADe 2018. Łódź University of Technology, 2018= / =Chapter in *Book Title*, 2019=
+ American spelling (-ize, color, program, modeling) in own text; quotes, guest bios/abstracts, published abstracts and titles stay as written
+ =videogame= (one word)
+ Dashes: en dash for ranges (=2016–2017=, =May 4–6=, =13.00–13.45=); closed em dash in sentences (=word—word=);
  spaced en dash as separator in lists and titles (=Valentin Moser – Chronicles=)
+ Names: lumbung radio, documenta fifteen, project Anywhere, eCAADe, TU Wien, Künstlerhaus, Łódź
+ DOIs as bare identifiers (=doi: '10.xxxx/...'=)
+ New events: =hugo new event/26-name/index.md= (uses =archetypes/event.md=); starter examples in =_starter-examples/=
+ Titles: works (talks, papers, artworks, courses) keep their published/announced title; descriptive page titles in sentence case (e.g. =Second prize in the Zeiss VR One app contest=)
