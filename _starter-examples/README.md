# Starter examples (not built)

Example pages from the original Wowchemy/Academic starter template, kept for reference.
Hugo does not build this folder; it is outside `content/`.

- `event/example`, `project/example`, `project/_external-project`: sample pages showing all front-matter fields
- `publication/t-*`: publication templates (conference paper, journal article, preprint)
- `post/`: starter blog posts (incl. writing-technical-content: shortcode/markdown reference)
- `slides/`: reveal.js slide examples

To start a new event from a template, use the archetype instead: `hugo new event/26-name/index.md`
(see `archetypes/event.md`).
